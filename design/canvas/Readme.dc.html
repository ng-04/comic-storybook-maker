README

Static React + Vite front end on S3 + CloudFront. Cognito for sign-in. Every AI and storage call goes through one api module to your Lambda backend, so there are no keys and no model names in the browser. Long work is asynchronous: start a job, get a jobId, poll /jobs/{id}.

API contract

All calls send Authorization: Bearer <Cognito ID token>. Errors are { code, message }. Model-calling endpoints return 202 { jobId } immediately, well under API Gateway's 29-second limit.

Image retry ladder

The backend tries with photo → without photo → text only on IMAGE_SAFETY / IMAGE_OTHER. It returns fallbackNote (empty when step 1 worked), which the UI shows as written. If all three fail, the job fails with { code, message, attempts } and the UI offers "edit prompt and redraw".

Proposed additions

  • POST /characters, PATCH /characters/{id}: sheets are drawn before a story exists, so characters need IDs first.
  • POST /stories/{id}/pages/{n}/rewrite → job → { caption, imagePrompt }.
  • DELETE /me/images and DELETE /uploads/{id}.
  • panelImages on grid results, and a single-panel redraw endpoint.
  • fallbackNote on the sheet result too.
  • Optional: DELETE /jobs/{id} (true cancel), DELETE /stories/{id}/share (revoke), public GET /share/{token}.
